Paginas Web usadas

Una página web es un documento escrito en lenguajes digitales como HTML, accesible desde un navegador web y que muestra diversos tipos de contenido digital, incluyendo texto, vídeos o fotografías. La página web puede entenderse como la unidad básica de contenido digital, y en ella se activan diferentes experiencias para el usuario que la visita: en una página web, los usuarios pueden informarse, entretenerse, participar, realizar una transacción…

Youtube

Wikipedia

Caracteristicas de una Pagina Web

La página web es accesible para los usuarios con una conexión a internet

Cuenta con una estructura basada en lenguaje HTML, además de lenguajes de diseño como CSS y JavaScript

Tiene capacidad de incluir texto y archivos multimedia, como imágenes, vídeos o audio.

Puede incorporar enlaces a otras páginas

Está asociada a una URL única que da acceso a la página (por ejemplo www.beedigital.es)

Está almacenada en un servidor web a través de un hosting

Reflexion

Una página web es la ventana digital que conecta tus ideas con el mundo entero,
su diseño y contenido transforman un simple clic en una oportunidad infinita.
